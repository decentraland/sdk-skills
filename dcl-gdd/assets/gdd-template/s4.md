### 4.3 Two return hooks

*Choose exactly two mechanisms. At least one must create a concrete reason to return the next day (D1). Use this menu as inspiration, or add your own — the menu is guidance: delete it before submitting.*

| Example mechanism | Return reason it is meant to create |
|---|---|
| **Appointment timer** — something finishes, respawns or unlocks at a known future time | A known completion time gives the player a concrete reason to remember. |
| **Daily goals + streak** — rotating daily tasks, escalating reward track | A visible routine and next milestone; allow recovery instead of punishing resets. |
| **Weekly leaderboard reset / small leagues** — rank inside small groups, fresh start weekly | A deadline and achievable fresh start create a weekly rhythm without requiring a new level. |
| **Named rival** — a specific player to beat, who learns who beat them back | A specific person turns a score into a relationship: "Marta beat your 47.2" is a return reason no anonymous board gives. |
| **Collection** — visible x/N progress toward a displayable reward | Visible unfinished progress creates a clear next objective; define what happens when the set is complete. |
| **Recurring scheduled event** — e.g. every Friday 20:00 UTC | A fixed time creates a shared appointment — the time itself is the return reason; an Event listing and an optional community channel only remind. |
| **Team / crew obligation** — small persistent groups with shared goals | A shared goal turns return into a social commitment: "my crew expects me." |
| **Season track** — a free time-limited progress track (6–8 weeks, running live after launch) | A deadline and fresh start create a comeback moment; align timing with program cycles and keep latecomers useful. |
| **Async traces** — things players leave behind that others discover later | Player traces connect visits when few people are online; account for storage, moderation, and expiry. |

# Deliver research within its resources

Use for prior art, audience and platform research, with or without delegation. Keep the
agreed breadth: a library for future uses is not limited to today's playable. Organise the
work so inspected findings become usable records even if the search stops early.

## Plan the pass and its finish

Name the questions, useful directions and intended records before searching. Use available
time/token limits as a shared budget, including workers and tool helpers, not a fresh allowance
for each worker. Leave room for source checks, writing, reconciliation and the final handoff.
When the environment reports remaining resources, use that report; do not invent token counts.
Without a counter, work in manageable batches and reassess before expanding the search.

Give workers complementary questions, relevant existing records, output paths and the resource
boundary. Pass this guide as well as the topic guide. A clarification may belong to an existing
assignment: update it through supported communication, or keep it for consolidation if that is
unavailable. Start another worker only for a distinct unanswered question within the remaining
budget. A list of example games is a map of leads, not an instruction to exhaust every one.

## Save while investigating

After each useful batch of inspected sources, write the findings to the intended research
record instead of waiting for the whole search. Keep the source/locator, what it establishes,
scope and uncertainty, possible use in this game, and promising leads still uninspected. Mark
the record in progress until the pass is finished. Use the existing reference library and
question-based files; avoid empty scaffolds or a new file for every source.

Before another batch, compare what is already saved with the requested breadth, remaining
gaps and available resources. Follow a lead when it adds an option, resolves a meaningful
uncertainty or checks an important claim. Preserve relevant future possibilities; distinguish
leads from verified findings rather than silently deleting them to fit the current build.

## Finish and reconcile

At the agreed boundary or an environment signal to finish, turn the saved work into a useful
partial or complete result. Finish writing and checking that result before opening new search
directions. Name the uncovered questions and why they remain open; an exhausted budget is not
evidence of exhaustive coverage. A further pass needs the owner's choice.

Workers return their record paths, recommendations and limits. The coordinating agent reads
the records, checks material source/client qualifiers and reconciles them with the latest
design. Update the affected GDD passages and reference links; remove superseded claims instead
of appending a contradictory correction. A tool log or a worker's summary alone is not the
saved research library. If a worker did not finish, keep that dependency and the handoff's
incompleteness visible rather than calling the research integrated.

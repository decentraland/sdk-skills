# Reserved helper files

Two lowercase-named helper modules live in `src/ui/`. The Creator Hub UI editor scaffolds them itself and never lists them as UI roots — the lowercase basenames are what keeps them out of the roots list. In a scene the editor has not touched yet, create them **verbatim**: the parser recognizes the constructs by this exact shape.

Both are ordinary SDK code and safe to hand-edit, but any structural change risks breaking recognition.

---

## `src/ui/interaction.tsx`

The `useInteraction` helper: react-ecs has no native hover/press styling, so this layers style objects and tracks the pointer state that selects them. Layer precedence is `base → active → hover → press` (later layers win), layers are deep-merged so a layer may override one nested field, and handlers declared in a layer still fire (they are chained after the state trackers, not replaced).

```tsx
// Generated by the Creator Hub UI editor — interaction-state styling.
//
// react-ecs has no native hover/press styling, so this helper layers style
// objects and tracks the pointer state that selects them:
//   base -> active -> hover -> press   (later layers win)
// Layers are deep-merged, so a layer may override a single nested field (just
// uiBackground.color) without dropping its siblings. Event handlers declared in
// a layer still fire — they are chained after the state trackers, not replaced.
//
// This is plain react-ecs and safe to hand-edit; the editor reads this shape
// back out of your UI files.
import ReactEcs from '@dcl/sdk/react-ecs'
import type { EntityPropTypes, UiLabelProps } from '@dcl/sdk/react-ecs'

// The known props are typed for autocomplete; the open index signature keeps
// element-specific props (an Input's placeholder, a Dropdown's options) from
// erroring in a strict scene tsconfig without intersecting three prop types
// whose onChange signatures conflict.
export type InteractionLayer = EntityPropTypes & Partial<UiLabelProps> & Record<string, unknown>

export interface InteractionLayers<T extends InteractionLayer = InteractionLayer> {
  // Generic in the BASE layer so the return type keeps its required props: a
  // Label's `value` is required by UiLabelProps, and once it lives in the base
  // layer only a `T`-shaped return satisfies `<Label {...styles} />`. The
  // override layers stay loosely typed — they are partial by nature.
  base?: T
  hover?: InteractionLayer
  press?: InteractionLayer
  active?: InteractionLayer
}

type Bag = Record<string, unknown>

function isPlainObject(value: unknown): value is Bag {
  return typeof value === 'object' && value !== null && !Array.isArray(value)
}

function merge(base: Bag, over: Bag | undefined): Bag {
  if (!over) return base
  const out: Bag = { ...base }
  for (const key in over) {
    const next = over[key]
    const prev = out[key]
    out[key] = isPlainObject(next) && isPlainObject(prev) ? merge(prev, next) : next
  }
  return out
}

const chain =
  (track: () => void, own: (() => void) | undefined) =>
  () => {
    track()
    own?.()
  }

export function useInteraction<T extends InteractionLayer = InteractionLayer>(
  layers: InteractionLayers<T>,
  active?: boolean,
): T {
  const [hovered, setHovered] = ReactEcs.useState(false)
  const [pressed, setPressed] = ReactEcs.useState(false)

  let bag: Bag = (layers.base ?? {}) as Bag
  if (active) bag = merge(bag, layers.active as Bag | undefined)
  if (hovered) bag = merge(bag, layers.hover as Bag | undefined)
  if (pressed) bag = merge(bag, layers.press as Bag | undefined)

  const style = bag as InteractionLayer
  // The merge is dynamic, so the T-shaped result is asserted: every key of the
  // base layer survives it (overrides only replace values, never delete keys).
  return {
    ...style,
    onMouseEnter: chain(() => setHovered(true), style.onMouseEnter),
    onMouseLeave: chain(() => {
      setHovered(false)
      setPressed(false)
    }, style.onMouseLeave),
    onMouseDown: chain(() => setPressed(true), style.onMouseDown),
    onMouseUp: chain(() => setPressed(false), style.onMouseUp),
  } as T
}
```

Notes:

- `useState` is exported on the `ReactEcs` **namespace**, not as a named export of `@dcl/sdk/react-ecs` — hence `ReactEcs.useState`. A bare `import { useState }` does not resolve.
- The file contains no JSX, so it needs no `@jsx` pragma; `ReactEcs` is imported purely for the hook.
- Import it in UI files as `import { useInteraction } from './interaction'`.

### Usage shapes the parser recognizes

Canonical (const + single spread):

```tsx
const card = useInteraction(
  {
    base: { uiTransform: { width: 320, height: 180 }, uiBackground: { color: { r: 1, g: 1, b: 1, a: 1 } } },
    hover: { uiBackground: { color: { r: 0.95, g: 0.95, b: 0.95, a: 1 } } },
    press: { uiBackground: { color: { r: 0.9, g: 0.9, b: 0.9, a: 1 } } },
    active: { uiTransform: { display: 'none' } },
  },
  state.hidden === true,
)
return <UiEntity {...card} onMouseDown={() => openCard({ state, props })}>…</UiEntity>
```

- Any subset of the four layers is valid; a `base`-only call is fine.
- The second argument (the `active` driver) may be any expression — `state.tab !== 'video'`, `props.active === true`, `state.cycle % 8 === 3`. It is stored verbatim and stays editable.
- Layer objects must be **static object literals** with literal or bare-reference values, exactly like a JSX style attribute. A bound value inside a layer is fine (`base: { uiTransform: { width: state.panelWidth } }`).
- `variant` / `disabled` on a `Button` are not styles and do not belong in a layer.
- Additional attributes may sit next to the spread and win over it (the spread is emitted first).

## `src/ui/platform.tsx`

Backs the one supported structural conditional (desktop/mobile variants).

```tsx
// Generated by the Creator Hub UI editor — platform (device) variants.
//
// The explorer reports the platform asynchronously, so this reads 'desktop' for
// the first few frames; react-ecs re-renders every tick, so the UI switches as
// soon as it resolves. 'web' counts as desktop.
//
// This is plain SDK code and safe to hand-edit; the editor reads this shape back
// out of your UI files.
import { isMobile } from '@dcl/sdk/platform'

export type UiPlatform = 'desktop' | 'mobile'

export function usePlatform(): UiPlatform {
  return isMobile() ? 'mobile' : 'desktop'
}
```

### Recognized variant shapes

```tsx
// at the component's return
const platform = usePlatform()
return platform === 'mobile' ? <PhoneMenu /> : <DesktopBar />

// as a JSX child
<UiEntity uiTransform={{ width: '100%', height: '100%' }}>
  {platform === 'mobile' ? <PhoneRail /> : <DesktopRail />}
</UiEntity>

// unauthored branch
{platform === 'mobile' ? <PhoneOnlyHint /> : null}
```

Also accepted: `!==`, reversed operands (`'mobile' === platform`), and an inline `usePlatform() === 'mobile'` with no const. Both branches must be a single JSX element or the literal `null`, and at least one must be an element — anything else (a fragment, a nested conditional, a call) makes the whole subtree opaque.
